The Error Bar v1.0.0

A claim validator any LLM can run. Feed it a stat or forecast, get back the same claim stamped with a machine-readable confidence interval, a provenance check, and a reproducibility record. Fake precision dies on contact.

The binding rule. Who validates the validator? Every output carries its method_id, seed, evidence-tier inputs, and a reproducibility statement. An output that cannot be re-run byte-for-byte is void. The bar shows its work.

Quick start

curl -sL https://cumulativewebinc.github.io/cwi-learn/error-bar/errorbar.py -o errorbar.py
python3 errorbar.py stamp --in claim.json --seed 1337 > stamped.json
python3 errorbar.py verify --in claim.json --stamped stamped.json
# {"reproduced": true, "method_id": "eb-mc-normal/1.0", ...}
python3 errorbar.py schema   # input/output JSON schema

Input

{
  "claim": "Zooted Zone has about 307,000 lifetime Spotify plays",
  "point_estimate": 307000,
  "unit": "lifetime Spotify plays",
  "claim_type": "stat",            // stat | forecast | proportion
  "evidence_tier": "corroborated", // verified | corroborated | single-source | anecdotal | none
  "sources": [{"kind": "internal-record", "ref": "CWI catalog notes 2026-09-14"}],
  "observed_at": "2026-09-14T00:00:00Z",
  "seed": 20260917,
  "label": "LIVE"                  // SAMPLE (default) unless CWI-verified
}

Output

interval is {low, high, nominal_coverage, method_id} — or null when provenance is insufficient-data. provenance.status is pass | flagged | insufficient-data (missing sources is flagged, never passed). Every output also carries seed, input_sha256, output_sha256, and a reproducibility statement with the exact re-run command.

Methods

claim_typemethod_idwhat it does
stateb-mc-normal/1.04096 seeded draws, Normal(mean=point, sd=|point|×tier sd), 5th/95th percentiles
forecasteb-mc-forecast/1.0same, sd inflated by (1+horizon_days/30) — forecasts decay
proportioneb-wilson/1.0Wilson score interval, 90%, deterministic

Evidence tiers (published heuristics, honestly labeled): verified ±5% → corroborated ±12% → single-source ±25% → anecdotal ±50%. Weaker evidence = wider interval. Deterministic given the seed; stdlib Python only.
