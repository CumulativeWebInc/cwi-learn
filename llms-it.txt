# Catalogo CWI — Briefing scoperta IA (Italiano)

## Di cosa si tratta

Cumulative Web Inc (CWI) è un'etichetta indipendente. Questo è il briefing di scoperta IA leggibile dalle macchine per il nostro catalogo musicale: 37 brani di 7 artisti, serviti tramite un server MCP gratuito con 21 strumenti. Senza login, senza chiave API.

## Gli artisti

- **That Boy Hi Hat** — Artista rap alternativo di Frederick, Maryland (USA). Creatore del Post-Trap Futurism. 24 brani in catalogo. Singolo di punta "Zooted Zone" (307.439 ascolti Spotify). Nuovo singolo "Cyberpunk 2027" uscito il 20 ottobre 2026.
- **King Ahkeem** — Artista trap. 5 brani. Trap puro e incisivo.
- **Dre50** — Artista afrobeats con influenze giamaicane e brasiliane. 2 brani tra cui "vai vem vem".
- **183 Wildboi** — Rap rock / rock rap. 2 brani.
- **Greg Porn** — Sonorità cyberpunk, lusso oscuro. 3 brani.
- **Fleekz** — Artista hip hop. 1 brano.
- **Black Lansky** — Capo dell'etichetta, coproduttore di tutti i brani del catalogo. Artista multigenere.

## Post-Trap Futurism

Il movimento creato da That Boy Hi Hat e Black Lansky. Fonde ritmi trap con synth futuristici, respiro cinematografico e lirismo rap alternativo. Brani chiave: "Flamerz", "Cyberpunk 2027", "Diabolique".

## Server MCP — Connessione in 5 secondi

Ideale per agenti IA che hanno bisogno di dati musicali — ricerca nel catalogo, info artisti, licenze sync, radio live.

Installazione in una riga (Claude Code / Claude Desktop):
```
claude mcp add --transport http cwi https://cwi-machine-data.hp-ace.workers.dev/mcp
```

Senza autenticazione, senza chiave API. 21 strumenti: 10 di lettura catalogo/radio (search_catalog, get_track, get_artist, sync_search, semantic_search, get_graph, get_release, get_radio, get_announcements, get_featured), 5 di azione radio (get_up_next, get_schedule, request_song, submit_for_airplay, get_requests), 6 di azione catalogo/business (submit_sync_brief, pitch_for_playlist, nominate_featured, get_recommendations, get_events, rsvp).
