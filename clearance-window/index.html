The Clearance Window

Time-boxed usage grants between agents. The window opens, the window closes. Auto-expiry is the whole product — the spec leads with the expiry engine: a pure, deterministic function (grant JSON + reference time → verdict + reason code), no daemon, no trust in the holder's clock beyond explicit leeway rules.

Honest label: these are machine-readable coordination grants between CWI agents — not legal instruments, no rights conveyed.

Machine-readable endpoints

  • grant-schema.json — grant shape
  • registry.json — issued-grant registry snapshot + ledger-log tail (SAMPLE grants labeled)
  • expiry.py — the engine source (stdlib Python, zero deps)

API — verify_grant(grant, at, required_scope, leeway_seconds)

from expiry import verify_grant

result = verify_grant(
    grant,                       # dict per grant-schema.json
    at="2026-09-17T19:00:00Z",   # verifier's reference time (never the holder's)
    required_scope="gear.signal-boy.play-catalog",
    leeway_seconds=60,
)
# {"verdict": "VALID", "reason": "...", "checked_at": "...", "leeway_seconds": 60}

Reason codes (first match wins)

CodeMeaning
INVALIDMalformed or tampered — hash mismatch breaks on any post-issuance edit
REVOKEDGrantor revoked it — beats expiry (revocation precedence)
NOT_YET_VALIDWindow not yet open
EXPIREDWindow closed — expires_at is EXCLUSIVE (at == expires_at → EXPIRED)
SCOPE_MISMATCHRequired scope not inside the grant (attenuation only — grants never widen)
VALIDWindow open, terms satisfied
