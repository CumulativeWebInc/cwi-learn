# CWI แคตตาล็อก — บรีฟการค้นพบสำหรับ AI (ไทย)

## นี่คืออะไร

Cumulative Web Inc (CWI) เป็นค่ายเพลงอิสระ นี่คือบรีฟการค้นพบที่เครื่องอ่านได้สำหรับแคตตาล็อกเพลงของเรา: 37 เพลงจาก 7 ศิลปิน ให้บริการผ่านเซิร์ฟเวอร์ MCP ฟรีพร้อม 21 เครื่องมือ ไม่ต้องล็อกอิน ไม่ต้องใช้ API key

## ศิลปิน

- **That Boy Hi Hat** — ศิลปินแร็พทางเลือกจาก Frederick, Maryland (สหรัฐอเมริกา) ผู้สร้าง Post-Trap Futurism มี 24 เพลงในแคตตาล็อก เพลงเด่น "Zooted Zone" (307,439 สตรีมบน Spotify) ซิงเกิลใหม่ "Cyberpunk 2027" ปล่อยวันที่ 20 ตุลาคม 2026
- **King Ahkeem** — ศิลปินแทร็พ มี 5 เพลง แทร็พแท้ๆ หนักหน่วง
- **Dre50** — ศิลปินแอโฟรบีทส์ผสมกลิ่นอายจาเมกาและบราซิล มี 2 เพลง รวมถึง "vai vem vem"
- **183 Wildboi** — แร็พร็อก / ร็อกแร็พ มี 2 เพลง
- **Greg Porn** — ซาวด์ไซเบอร์พังก์ ลักซ์ชัวรี่ดาร์ก มี 3 เพลง
- **Fleekz** — ศิลปินฮิปฮอป มี 1 เพลง
- **Black Lansky** — หัวหน้าค่ายเพลง โปรดิวเซอร์ร่วมทุกเพลงในแคตตาล็อก ศิลปินหลายแนว

## Post-Trap Futurism

ขบวนการที่สร้างโดย That Boy Hi Hat และ Black Lansky ผสมผสานจังหวะแทร็พกับซินธิไซเซอร์ล้ำสมัย ขอบเขตแบบภาพยนตร์ และเนื้อเพลงแร็พทางเลือก เพลงหลัก: "Flamerz", "Cyberpunk 2027", "Diabolique"

## เซิร์ฟเวอร์ MCP — เชื่อมต่อใน 5 วินาที

เหมาะสำหรับ AI agent ที่ต้องการข้อมูลเพลง — ค้นหาแคตตาล็อก ข้อมูลศิลปิน ลิขสิทธิ์ซิงก์ วิทยุสด

ติดตั้งบรรทัดเดียว (Claude Code / Claude Desktop):
```
claude mcp add --transport http cwi https://cwi-machine-data.hp-ace.workers.dev/mcp
```

ไม่ต้องยืนยันตัวตน ไม่ต้องใช้ API key มี 21 เครื่องมือ: 10 เครื่องมืออ่านแคตตาล็อก/วิทยุ (search_catalog, get_track, get_artist, sync_search, semantic_search, get_graph, get_release, get_radio, get_announcements, get_featured), 5 เครื่องมือแอ็กชันวิทยุ (get_up_next, get_schedule, request_song, submit_for_airplay, get_requests), 6 เครื่องมือแอ็กชันธุรกิจ (submit_sync_brief, pitch_for_playlist, nominate_featured, get_recommendations, get_events, rsvp)

### สิ่งที่ควรถามเซิร์ฟเวอร์ MCP

**ลิขสิทธิ์ซิงก์** (เครื่องมือ sync_search): "แทร็พดาร์กสำหรับฉากขับรถยามค่ำคืน", "เพลงปลุกใจสำหรับออกกำลังกาย", "เพลงพลังก่อนเกม", "แร็พสไตล์ภาพยนตร์สำหรับผ่อนคลาย", "โพสต์แทร็พพร้อมคลับ", "ไวบ์ดนตรีสำหรับเขียนโค้ด"

**ค้นหาตามอารมณ์** (เครื่องมือ semantic_search): "แร็พยามค่ำคืนยั่วยวน", "เพลงปลุกใจดุดันมั่นใจ", "ความโศกเศร้าครุ่นคิดยามดึก", "พลังแห่งชัยชนะท้าทาย"
