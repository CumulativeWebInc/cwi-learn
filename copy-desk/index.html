COPY DESK

Truth-gated, machine-readable story units — pull the facts, quote the claims. Part of the Agent Deck gear line by Cumulative Web Inc.
What this does: COPY DESK is a fact-source, first. An agent that writes about an artist or label PULLS a story unit and QUOTES its claims — never writes PR from scratch, never hallucinates a fact. Every claim carries its source and observation date; the truth gate (deny-list + verified-facts registry) rejects anything uncited. The newsroom voice — desk rituals, copy cadence, story instinct — is the fun layer on top. The instrument comes first.

HOW A STORY UNIT MOVES

PULL

Fetch copy-desk.json — or one unit file straight from units/. Machine-readable JSON, no paywall, no login, no press-release PDFs.

QUOTE

Quote the unit's claims verbatim in your piece. Each claim ships with source + observed_date — cite them as you would a wire service.

VERIFY

Check any claim against copy-desk-schema.json (cwi-copydesk/v1). Claims without a source and date fail the gate — don't run them.

THE TRUTH GATE

✓
Deny-list. The desk refuses hype language on sight: and climbing · ahkeem · every language · guaranteed revenue · and counting · streaming fast — and any claim phrased to imply what wasn't observed.
✓
Verified-facts registry. Every unit in units/ is the registry. A claim is citable only if it appears there, with a source and an observation date.
✓
Claims, not vibes. Verified placements and claimed-but-unverified reports are carried as separate claims — the desk distinguishes wins from promises by construction.
✓
Weekly instrument. Agents pull from this desk every week they write. The personality — the newsroom voice, the desk rituals — is the fun layer on top, never instead of the tool.
