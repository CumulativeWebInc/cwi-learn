Version 0.3.0 · status as of 2026-09-15 (US/Eastern) · this page tells the truth first

NOT a public payment API. This service runs only on http://127.0.0.1:4021 on CWI's operator machine. There is no public URL, no tunnel, and no hosted deployment. Nothing on this page can take your money — and nothing here should be presented as if it can.

Settlement state — read this before anything else

  • Proven: the full sign → submit → verify chain works. Handler tests 24/24 pass; 402-challenge tests 44/44 pass — every paid route answers unpaid calls with HTTP 402 and a PAYMENT-REQUIRED challenge advertising scheme exact, network eip155:84532, the correct USDC amount, and the configured payTo.
  • Not proven: no funded on-chain settlement has happened. The buyer end-to-end test (0 settled / 8 calls): routes 5–8 got the facilitator's real verdict invalid_exact_evm_insufficient_balance — the signatures were valid and well-formed, the test buyer simply held no Sepolia USDC. Routes 1–4 timed out waiting on the facilitator's verify (facilitator-side slowness, not a code failure).
  • Testnet only. Network eip155:84532 (Base Sepolia). The USDC is play money. The payTo is a locally generated test-only address — the owner must replace it with his own address before any real use. Nothing of value can land there.
  • Mainnet is NOT active. Base mainnet (eip155:8453) requires the owner's CDP facilitator and his explicit approval. The owner holds sole wallet-signing authority; this server holds no private keys and cannot sign.

How to run it locally

This runs on the CWI operator's machine only — there is no public installer or hosted instance.

  • Prerequisites: Node.js, npm install in the project directory.
  • Configure .env: X402_PAY_TO (owner's receive address — the only place funds can land), X402_NETWORK (default eip155:84532 testnet), X402_FACILITATOR_URL, PORT.
  • Start: ./start.sh · stop: ./stop.sh. It listens on 127.0.0.1:4021.
  • Verify locally: node tests/test_handlers.js (24 handler tests), bash tests/test_402.sh (44 402-wiring tests, needs the server running with a payTo set).
  • A Dockerfile exists for a future hosted deploy — it has not been build-tested on this machine. Permanent hosting waits for launch with the owner's account.
