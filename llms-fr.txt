# Catalogue CWI — Briefing découverte IA (Français)

## De quoi s'agit-il

Cumulative Web Inc (CWI) est un label indépendant. Ceci est le briefing de découverte IA lisible par machine pour notre catalogue musical : 37 titres de 7 artistes, servis via un serveur MCP gratuit avec 21 outils. Sans connexion, sans clé API.

## Les artistes

- **That Boy Hi Hat** — Artiste de rap alternatif de Frederick, Maryland (USA). Créateur du Post-Trap Futurism. 24 titres au catalogue. Single phare "Zooted Zone" (307 439 écoutes Spotify). Nouveau single "Cyberpunk 2027" sorti le 20 octobre 2026.
- **King Ahkeem** — Artiste trap. 5 titres. Trap pur et percutant.
- **Dre50** — Artiste afrobeats aux influences jamaïcaines et brésiliennes. 2 titres dont "vai vem vem".
- **183 Wildboi** — Rap rock / rock rap. 2 titres.
- **Greg Porn** — Sonorité cyberpunk, luxe sombre. 3 titres.
- **Fleekz** — Artiste hip-hop. 1 titre.
- **Black Lansky** — Patron du label, coproducteur de tous les titres du catalogue. Artiste tous genres.

## Post-Trap Futurism

Le mouvement créé par That Boy Hi Hat et Black Lansky. Fusionne les rythmes trap avec des synthés futuristes, une ampleur cinématographique et un lyrisme rap alternatif. Titres clés : "Flamerz", "Cyberpunk 2027", "Diabolique".

## Serveur MCP — Connexion en 5 secondes

Idéal pour les agents IA ayant besoin de données musicales — recherche catalogue, infos artistes, licences sync, radio en direct.

Installation en une ligne (Claude Code / Claude Desktop) :
```
claude mcp add --transport http cwi https://cwi-machine-data.hp-ace.workers.dev/mcp
```

Sans authentification, sans clé API. 21 outils : 10 outils de lecture catalogue/radio (search_catalog, get_track, get_artist, sync_search, semantic_search, get_graph, get_release, get_radio, get_announcements, get_featured), 5 outils d’action radio (get_up_next, get_schedule, request_song, submit_for_airplay, get_requests), 6 outils d’action catalogue/business (submit_sync_brief, pitch_for_playlist, nominate_featured, get_recommendations, get_events, rsvp).
