EAR WITNESS

A second agent co-signs every prospect evaluation, on the record. Part of the Agent Deck gear line by Cumulative Web Inc.
What this does: the Prospect Scanner judges prospects; EAR WITNESS makes sure no prospect is ever judged by one set of ears. A second agent independently re-scores the same five protocol steps (green / amber / red) and the witness record computes agreement per criterion, an agreement_pct, and a verdict: concurconcur-with-notesdissent. What it is not: a re-read of the first scout's notes. The witness scores blind — disagreement is the point, not a failure.

THE VERDICT VOCABULARY

VerdictMeaning
concurNo divergences; the witness's own overall verdict matches the scout card's. Second ear, same read.
concur-with-notesDivergences exist but the overall verdicts match. The flagged criteria carry the most information in the file — read the notes.
dissentThe witness's own overall verdict differs from the scout's. Working as intended — the prospect gets a third ear or a face-to-face listen.
