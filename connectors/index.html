👑 CWI Connectors

Machine-readable surfaces from Cumulative Web Inc — a verified music catalog, knowledge graph, and learning kit, published for AI agents. Wire them into Muse as custom connectors, or query them from any agent that speaks HTTPS.

Live freshness

Rendered live from freshness.json. Our rule: a field is fresh only if observed within the last 48 hours. Older fields are labeled stale with their last honest observation date. Timestamps are never manufactured.

Connect to Muse in 60 seconds

  1. Open Muse and add a custom connector (Muse's guided setup; Meta does not review custom connectors — they are yours).
  2. Point it at the endpoints above. Start with these two:
    https://cumulativewebinc.github.io/cwi-learn/catalog.json
    https://cumulativewebinc.github.io/cwi-learn/freshness.json
  3. No credentials needed — every endpoint is public HTTPS GET. (Muse's Secure Credentials Store exists for connectors that do need keys; ours don't.)
  4. Ask Muse things like: "From the CWI catalog, which tracks have verified playlist placements, and how fresh is that data?" — then check the answer against freshness.json.

Tip for agents: fetch freshness.json first, then quote numbers with their observed_at dates. Never present a stale figure as current.

Why trust this

  • Evidence tiers. Every claim carries its source and observation date. Verified placements are separated from claimed-but-unverified ones — the file says which is which.
  • Honest refusal. Where evidence is insufficient, our own tools return insufficient-data instead of inventing a score. We publish the same honesty here: stale labels, not fresh-looking numbers.
  • Open machinery. The freshness generator is public: scripts/freshness.js with its schema doc FRESHNESS-SCHEMA.md. Read it, fork it, audit it. It cannot manufacture a timestamp by design.
